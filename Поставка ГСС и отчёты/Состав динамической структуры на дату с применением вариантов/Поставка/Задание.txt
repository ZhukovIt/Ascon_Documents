1. Серверный отчёт

Название: Состав динамической структуры
Описание: Формирует отчёт "Состав динамической структуры" путём рекурсивного обхода динамической структуры с применением правил версионного конфигурирования.
Область применения отчёта: Объекты
Тип скрипта: C# ServerApi скрипт
Тип шаблона: Шаблон FastReport-документа (.frx)

2. Скрипт
Архив скрипта: Скрипт.zip
Тип скрипта: C# ServerApi скрипт
Файл запуска: bin/Release/net8.0/DynamicStructureReport.dll

3. Серверный шаблон
Архив шаблона: Шаблон отчёта Состав динамической структуры.frx

4. Входные параметры

Глубина разузловки
Тип параметра: Целое число
Значение по умолчанию: 3

Тип связи
Тип параметра: Строка (Однострочное текстовое поле)
Значение по умолчанию: Состоит из ...

Количество знаков после запятой
Тип параметра: Целое число
Значение по умолчанию: 2

Режим учёта вариатного конфигурирования
Тип параметра: Целое число
Описание:
0 - не учитывать; 
1 - учитывать;
2 - учитывать из текущего сеанса.
Значение по умолчанию: 2
Мин. значение: 0
Макс. значение: 2
